类型

  Varchar与char区别：

Varchar 是可变长，需要字节存储长度，不大于255，需要1字节，特殊的如果表格使用ROW_FORMAT=FIXED，则变为固定长度。一般不能直接设定最大值，虽然在mysql中看是变长，但是对于内存来说是直接开辟全部长度，以避免放不下情况，会浪费资源，同时Varchar在更新时，也会出现页内存储不够的情况，MylSAM会将行拆成不同的片段存储，InnoDB则需要分裂页来使行可以放进页内，允许最大长度为65535个字节，同时列共享（相加）。
char 是固定长度，不够部分用空格补充，允许最大长度为255个字符，

  AUTO_INCREMENT 自增，所修饰字段具备如下特性：

1、字段不能为null，即设定NOT NULL;
2、字段必须有唯一索引，即不允许有重复值，UNIQUE标识为唯一索引，不允许重复，但是可以为空，主键索引，通过设置主键自动创建，其不允许重复同时不允许为空，所以一般该字段设定为主键或者是唯一不为空字段;
3、字段类型必须为整型;
4、字段达到最大值时，失效；

  主键创建可以在字段声明时利用PRIMARY KEY设定，也可以在字段最后加入PRIMARY KEY(‘字段1’，‘字段2’)，我认为应该使用后者，当然如果只设定一个字段为主键可以使用前者，但是后者舍得主键与字段分开，便于阅读，同时便于确定主键。主键只能指定一个，但是可以包括多个字段。

1、CREATE TABLE table_1(
    'id' int NOT NULL PRIMARY KEY AUTO_INCREMENT,
    'name' varchar(10) NOT NULL
)ENGINE=InnoDB AUTO_INCREMENT=7 DEAFAULT CHARSET=utf8;
2、CREATE TABLE table_2(
    'id' int NOT NULL ATUO_INCREMENT,
    'name' varchar(10) NOT NULL,
    PRIMARY KEY('id')
)ENGINE=InnoDB AUTO_INCREMENT=7 DEAFALT CHARSET=utf8;

  唯一键UNIQUE KEY，设定与PRIMARY KEY差不多，一个是声明字段时加UNIQUE，另一个在最后使用UNIQUE KEY ‘标识名称’ (‘字段名1’,‘字段名2’…)，也可以在修改表命令中使用ALTER TABLE <数据表名> ADD CONSTRAINT <唯一约束名> UNIQUE<列名>，也可ALTER TABLE ‘表名’ ADD unique(‘字段名’)，或者create unique index ‘名称’ on ‘表名’ (‘字段名’)，删除表使用ALTER TABLE <数据表名> DROP INDEX <唯一约束名>；

1、创建UNIQUE KEY
a. CREATE TABLE table_1(
    'id' int NOT NULL PRIMARY KEY AUTO_INCREMENT,
    'name' varchar(10) NOT NULL,
    'id_card' char(13) NOT NULL UNIQUE,
)ENGINE=InnoDB AUTO_INCREMENT=7 DEAFAULT CHARSET=utf8;
b. CREATE TABLE table_1(
    'id' int NOT NULL PRIMARY KEY AUTO_INCREMENT,
    'name' varchar(10) NOT NULL,
    'id_card' char(13) NOT NULL,
    UNIQUE KEY 'id_unique' ('id_card')
)ENGINE=InnoDB AUTO_INCREMENT=7 DEAFAULT CHARSET=utf8;
c. CREATE TABLE table_1(
    'id' int NOT NULL PRIMARY KEY AUTO_INCREMENT,
    'name' varchar(10) NOT NULL,
    'id_card' char(13) NOT NULL
)ENGINE=InnoDB AUTO_INCREMENT=7 DEAFAULT CHARSET=utf8;
   ALTER TABLE table_1 ADD CONSTRAINT 'indexID' UNIQUE 'id_card';
   或者 CREATE UNIQUE INDEX 'indexID' on 'table_1' ('id_card');
3、删除唯一索引
ALTER TABLE table_1 DROP INDEX 'indexID';

《落凡尘》

  对于这部电影，我认为剧情设定我很喜欢，这部电影画面也是非常不错的，然后就是金线作为使用“武器”，我认为很符合中国文化，线可柔可刚，柔可缝补万物，守护一切事物，刚可切割万物，摧毁一切事物。
  神就是神化了的人，有善恶，有情感，有优劣。
  在人生低谷的时候，是最能看到人情冷暖的时候，没地位，就会遭到冷眼看待，而一旦处于高位，则会被人尊重与奉承。
  那些高高在上的人有几人有能力有实力，又有几人真正地心系于人，又有几人在灾难的时候能够去主动而又全力去帮助人。
  做的事是对的，但是手段是错误的，方法是错误的，那么这个事即使是对的，最后结果也是错的。
  追求本质本没错，但是得需要切实际，合人情。
  讲道理，说，谁都会说，但是说的好，真的会做吗?
  他们打着正义善良之旗帜，去做事情，但是，我想问真的是为别人吗，难道不是为了自己的利益与俸禄吗？
  每个人都有存在的意义，武将战乱时将会受人爱戴供奉，和平时可能会被人遗忘，但是不代表他没有存在意义，只不过职能改变了而已，变成了守护，有时我们应该基于时代与环境，来作出改变，不应过于抱怨环境，有时应该去改变自我。当然改变环境也是种方法，但是改变环境真的很难，甚至改变反而是错误的，因为这是符合大多数人的。
  金凤的师傅行动本身就是错的，他是为了他自己，而不是人类，为了人类他必不可能劈开天幕，因为人还是有求余于神的。
  中华文化需要传承 但是光继承不行，自然界有自然选择优胜劣汰适者生存，文化界也是如此。我们应该在继承的同时，要去创新，去创造，去改变，当然是在基于文化 尊重文化基础上。时代不断发展，必然文化适合的会留下，而不适合的会被遗弃，现在已有的文化就是这样留存下来的，所以我们要传承文化赋予文化新生命，创造新的符合时代的文化，这样才能留存于世。而且学习就是为了创造新的东西，就是为了在已有基础上创新新的事物，否则人类如何进步发展，所以我们要勇敢大胆而又理性细心地去创造属于我们这代人的东西与文化。落凡尘我认为是一个很好的尝试，将织女与星宿结合，是个不错的创新。不管对错与否，至少让我眼前一亮。

《抓娃娃》

  《抓娃娃》这部电影符合大众口味，搞笑风的电影，我发现很多电影开始逐渐去迎合大众口味了，确实，现在大部分人开始有时间去消费了，也愿意花钱在娱乐上了，所以大众尤其是占大头的普通民众，他们其实才是票房主题，而且很多时候更多地是去享受，所以需要迎合他们的情感，不需要过于技术化，而是要更有感情与平滑舒适，才能让他们愿意去看，也乐意去看，但是我们应该也要明白，其实现在人民对电影质量要求也在逐渐升高，因为他们也看了很多电影了，所以自然也有一定的电影基础了，所以我们也要明白电影已经不是随便拍就能博得很高的票房了，需要我们倾心来制作，不以过于利益去做，而是以做好电影为眼光去做，以真心换真心，而不是虚伪下的利益。
  韧性、珍惜、艰苦奋斗等好的品质确实好，但是我们要尊重时代，不能强制塑造环境，我认为很多品质，应该在日常生活中去注意，去培养，而不是刻意去塑造环境。
  当然环境重要性也应该重视，可以体验与感受，来理解良好品质重要性，毕竟口说的往往很难有感觉，切身感受才能真正地体会，但不能过度，最主要是让他们感受生活，理解现在的不易。
  培养对钱的敏感度，培养自我的钱财管理与运用，可以从注重生活开销的细节，管理自我财政支出抓起，学会成为钱的主人，提高自我财商，发现生活中的生财气息。
  不能过度保护孩子，我们应该引导他们，教育他们正确的思想与观念，但不能强迫他们，更不能以自己的意志强加于人，让他们自己寻找出路，让他们自己去寻找自己，我们只是导游，而路途是他们自己去走，给予他们自由，一定要让他们独立自主，有自我思考能力，有自己的价值观。当然很多时候我们都是为他们好，但是有没有想过他们也是一个独立的个体，独立的自我，我们过度干涉是给了他们好的人生，但是他们却丧失了自己的意志，变得看似懂事，其实是不敢、不想去反抗，去表达自我意志。我认为这是可悲的，而且往往这样的人一旦反抗，会更加激烈猛烈，人的天性不能被溟灭，我们应该给予孩子更多的自由空间。
  我们确实小时候经历了苦难，所以不想让孩子这样，这是对的，但是不是借口，我们应该清楚有些苦难应该让孩子自己去经历去感受，这样孩子才能真正意识到，真正体会到，动心忍性才会真正获得这个能力，那些课本上交的终归是理论，是虚无飘渺的，很难让人感同身受，更难让人真正的内化于心，每个阶段做每个阶段的事情，如果我们帮做了，那么他们就少了这个环节，少了必要的东西，积累下去，那么不就是我们说的瓷娃娃吗？让他们自己去思考去行动去感受，这是提升他们自己能力的最好的老师。所以，我们要学会放手，学会让他们自己去选择，去经历，去痛苦，这个是必要的，不能过度溺爱，注重孩子精神品质上的培养很重要，因为老师教的大多数是经验与知识 而不是意志精神思维能力层面，这需要自我去锻炼培养，但是一定要让他们真正的感受到，真正的认知，而非口头上、表面上甚至表层思维上的知道了。
  小时候培养健全的人格，强韧的意志，以及强大的内心，这是最重要的，这样未来遇到困难，遇到动心忍性的事情，才能够真正地扛过去，才能真正地提升，而不是被这些事情扭曲了自己的人格与心灵，成为一个扭曲的人。
  最后，抓娃娃寓意孩子要从娃娃抓起，我们确实应该从娃娃抓起，但是要合理而又理性，小孩小时候我认为不是主要学习知识，我们要注重品质与能力，同时注重孩子心灵与人格的培养，给未来打基础，而过于看重知识而忽视孩子心灵是不对的，这就好比捡了芝麻，丢了西瓜，长大我发现，我们很多时候知识都在重复学习，而且我认为知识在什么时候都能学习，而不一定要在小时候学，小时候学知识，最主要是培养品质与思维，而不是知识本身，记忆力也很重要，记忆是自考的保证，小时候知识不是最重要，而是知识背后的孩子健全人格与心灵以及他们本质思维、独立思考、自我思考能力。知识啥时候都能学习，而且很多知识长大了会发现没有用，而且都会被遗忘，能用的往往是未来你要从事所需要的知识，而且我发现大学了研究生了其实也能去学习那些知识，而且很多都是在大学重新学习，因此，我认为知识不是最主要的，因为知识啥时候都能去学习，都有人去教你，但是能力与心灵却不一样，小时候往往是培养能力与心灵最佳时期，而一旦错过了，长大了会发现已经很难去培养了，因为你会发现小时候的那些事情很难忘记，因为他们已经形成强制记忆以及习惯了。
  眼界也很重要，不能因培养艰苦奋斗而忽视眼界的重要，眼界能够拓展思维，层次高，能够让人看到优秀的人，从而学习他们的思维与品质，拓展自我思维，不要让他们脱节，否则即使培养了艰苦奋斗品质，他们也很难融入社会，融入这个世界，也不可能有符合世界的思维去创造你以为的辉煌，有些事情是学校教不到的，需要我们自己去感受去理解，去学习。
  遇见百思不得其解的事物，学会暂停，学会转弯，学会观察。
  不要企图向说谎的人寻求真实，要学会隐藏自己的真心，然后主动寻找，并设计让他们自己露出马脚或者放松警惕，以此提高接触真相的可能。

Hexo在post文件夹中子文件夹中创建文档

  随着hexo创建博客增多，我发现如果都是hexo new 文件时，所有文件都会出现在_post文件夹中，然后就无法很好地整理与查找文件了，因此需要通过子文件夹来进行分类，所以需要在创建时就将其分文件夹创建。

hexo new [post] -p 子文件夹/文件名 "文件题目"
[]是说创建什么模式，一般有post、draft、page模式，当使用post是会在/source/_post文件夹下创建，而draft则是在source/_draft文件夹下创建，page则是在source下创建。
附：

Options:
  -p, --path     Post path. Customize the path of the post.
  -r, --replace  Replace the current post if existed.
  -s, --slug     Post slug. Customize the URL of the post.

脚本延时变量

脚本

  在进行编写脚本时，发现了延时变量与非延时变量，记录一下。一般if语句被认为是一行命令，而if中往往有几行命令，此时命令可以被认为是并行的，但是如果使用了延时扩展，就如同被认为不同命令，相继执行。

setlocal enabledelayedexpansion ::开启延时扩展
set a = 2
if %a% =;=2 (::括号前要有空格

    set a=3
    echo !a!::当使用!!才会变成延时变量
    echo %a%
    ::此时!a!输出3，而%a%输出2。

)
pause
