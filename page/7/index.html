钩子方法

父类定义一个模版方法，即方法中没有内容，但是有参数，子类重写方法，此时使用多态赋值父类，父类调用钩子方法，通过方法参数就能钓到子类运行后的值，本质就是地址里的值改变了，地址其实没有变，钩子里有个小参数诱饵但是经过执行后，钓到了大的鱼，即将其附上了其他值。对于spirng中就是容器实例化的自动注入，实现多态，然后钩子调用。

  • 父类，但是方法上加了@Bean 此时如果IOC容器中有子类实例，则会多态自动注入到this中， 通过System.out.println(this);以及通过一个Controller类自动注入实现类，然后输出地址，你会发现其实是一个地址，也就是此时this其实就是其容器里注册后子类实例，然后spirng启动后会扫描执行该方法，此时容器是没有该类实例，只有实现类实例。
public  class Student {
    private String name;
    private int age;

    @Bean
    public void beanTest(){
        List<Integer>ss =new ArrayList<>() ;
        this.hook(ss);
        //ss相对于鱼饵
        System.out.println(this);
        //此时ss变成了大鱼，因为里面有东西了。
        System.out.println("勾中了"+ss.toString());

    }

	//钩子方法
    public void hook(List<Integer> s){
        System.out.println(name);
    }
    //有参构造
    public Student(String name, int age){
        this.name = name;
        this.age = age;
    }



    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

public @interface a{
    public String name() default 默认值;//将方法作为属性。
    String value();//特殊属性,即默认属性，即如果就只有一个value属性,则使用注解时无需指定value，默认赋值给value,注：此时的只有一个value属性，不仅代表注解只有一个value，如果注解有多个属性，但是多个属性都有默认值的话，则value属性也是可以不用写（value有默认值也是可以）。
        
}

元注解

注解注解的注解😏,第一个注解为动词，后面两个为名词。

  • @Retention() 声明注解作用时机，即保留周期
    • RetentionPolicy枚举类
      • SOURCE 只作用源码阶段，字节码文件中不存在。
      • CLASS（默认值）存在于源码与class文件中，但是运行时消失。
      • RUNTIME 一直到运行时都存在。
  • @Target() 声明注解作用位置
    • ElementType 枚举类
      • TYPE 类，接口
      • FIELD, 成员变量
      • METHOD, 成员方法
      • PARAMETER, 方法参数
      • CONSTRUCTOR, 构造器
      • LOCAL_VARIABLE ，局部变量

《荒野机器人》

  这部电影是一个不错的电影，幽默并有一定的深度，很多电影动作挺有意思的，画风也可以。
  这部电影最打动我的是弱小的小雁最后成长，即使不像其他大雁强壮，但是也依旧具有很好的能力，最重要的是其心要比其他的大雁更坚强与坚韧，也比其他大雁也更具有思想，这对我很有启发，我其实身体也很弱小，所以我很有感触，我明白了我们虽然身体不如别人强大，但是我们的内心却是可以不断增强，我们的思维也是可以不断提升，我们身体矮小，但是我们的思想与内心却是巨大的，这样的我们依旧是光彩依旧的。我们虽然比他们矮小，但是不代表我们就比他们差，我们通过我们自己的努力与提升是可以超过别人的，而最关键的是勇气与毅力。
  然后就是勇于创新与改变，机器人不像其他机器人，他自己覆写了自己的程序，当原有的程序已经不适合或者本身就是错误时，我们就应该勇于去创新与改进，而不是呆呆地不思改变，甘愿保持现状。
  其次就是我们有时也应该像机器学习，学习他们的纯粹，不管别人怎么看待你，不管环境怎么样，我们都应该去做我们认为应该做的和正确的事物，心无杂念同时心也要专注。
  很多人正因为缺少这些，他们才会去思考这些东西，很多人之所以这样做是因为他们从小认识到只有这样才会生存，即使他们其实心里明白这样不对，但是他们无可选择，电影里的狐狸就是代表。
  然后就是耐力， 大雁南飞需要飞翔的能力，同时还要有耐力，如果说飞翔是本身的基础能力，那么其耐力则是需要我们需要去锻炼的未来生活必要的，我认识到我未来工作需要耐力与毅力，需要能够一天去工作的耐力，也就是我锻炼我的技能外还要注重对身体精神上的锻炼，以能够未来能够面对到来的挑战。
  最后就是团队，未来的困难与挑战不是一个人能够解决，显然，当今世界的大部分成果都是多个人一起讨论解决的，是团队的智慧，最后，我想说我们应该明白未来人类一定是需要一起去工作，一定是一个大团结去面对未来的挑战，即使心不同，面对挑战就会求同存异，一起联合对抗挑战，因为这样才能将挑战困难打败。
  不去面对就永远都没有机会去克服和学习。踏出去就有可能，而不踏出去就一点也没有可能，我们去做了才会有思考的机会，而不做就永远驻足原地，学习一项技能就得需要把自己放在危险中，逼自己到绝境，心才会成长，才会不断地提升，才会做出改变，才会主动去做这件事，主动去学这件事，如同学习飞翔，需要将自己抛向空中，将自己处于悬崖边上，跳跃下去，这样你才会去煽动翅膀，去开始学习飞翔，如果你一直在安全舒适的环境，在平稳的地上行走，那么你就不可能去煽动你的翅膀，因为你没有这个意识和煽动的翅膀的必要，唯有绝境使得我们不断改变提升自我。去争取你想要的生活吧，一直小心翼翼就会使得时间流逝，最后什么也做不了。

《出走的决心》

  这部电影对我来说是一个题材很新颖的，因为我没怎么看过这种类型的电影，这部电影是我对家庭、社会、孩子之间一个新认知，整体不错，一定程度地描述了一些家庭现实。
  这部电影核心就是人被困住了，人好像和外界割裂了，与社会出现了割裂，电影最后李红出走的画面刚开始其实我是很不理解的，确实前面有三个人的都在进步的铺垫，而且确实李红已经两次放弃，付出了很多了，但是最后的离开感觉还会有点突兀，不过后面我也能够开始理解了，首先，我为什么会突兀，因为是在女儿关键时期竟然将事物甩给女儿，感觉有点不好，所以我感觉突兀，但是我后面在思考时发现其实这没有错，对于我们作为儿女往往对父母的付出当做理所当然了，明明有可以解决的问题的多个选择，但是因为父母这个选择，而选择了这个容易没有负担的选择，最后不也解决了，其实这也是一种懦弱，对事物与问题的妥协，不想着自己解决，而是依赖于父母，这其中有两点需要重视，第一点就是我们需要明白人是独立的人格，父母与孩子都是独立的人格，我们不应该为了自己的人生而让别人的人生去承担，当然父母为孩子付出，但是我们也应该让父母有自己的生活，尤其他们为了我们成长，贡献了大部分了，而如今我们成年了，应该自己去生活了，不应该在去过多地去劳烦父母了，尤其是父母已经给了我们这么多了，想要去过自己想要的生活了，我们确实应该放手了，往往我们说父母该放手了，但是其实有时候不是父母不放手，而是我们一直抓着父母，不是吗？其实很多时候我们多用点心、多出点力就可以解决问题，但是最后却选择父母这个最不费力的选择；第二点就是我们其实都会有这个行为心理，那就是对别人苛刻，能够看到别人的不好与错误，甚至说一点细节都能抓住，但是对我们自己却马虎了起来，很多细节都被忽视了，对自我的观察弱化了，很多对别人的苛责，自己明明也有但是却忽视了，李红女儿看到李红的懦弱，所以她很坚强，但是在李红离开时懦弱了，两次李红都是为了她而留下，李红丈夫说李红不明事理，但是他却没有发现他自己也不明事理，一点也没有理解李红，一点也没有站在别人的角度上思考问题，这里我要说就是李红丈夫自己农村亲人来，让李红喝酒的事件，我不是批评农村人，我自己也是农村人，我想说的是对我说的，就是心情确实重要，但是也要去理解别人，也要尊重每一个人，不要过多强加给别人自己的意志，尤其是不要把自己认为的事情当做理所当然，好了回归正题，我们缺少对自我的观察与思考，如同当局者迷，如同乱花渐欲迷人眼，只去看外面的世界，而忽视了自己内心的观察，这样人永远都不会改变，人永远无法适应改变的环境，一成不变怎么能够成长进步，当然我也清楚那就是对自己是需要心理上负担的，所以很多时候不是我们不观察，而是我们选择性逃避，心理清楚，但是也明白改变需要非常痛苦的经历，所以我们选择视而不见，而批评别人确实没有什么精神上负担，而且还会使自己高高在上，所以会更愿意去做。这两点我认为就是我需要注意的。
  接下来就是去分析电影反应的家庭主权、女性男性定位问题上，女性的偏见在社会确实存在，这我们不能改变，这需要的是社会的共识，我不讨论这个，我想说的是对于家庭我们应该去学着分担生活负担，而不是理所当然地全交给女人去做，当然可能一个家庭中丈夫去主要谋生，所以女人就去做家务，这确实是没问题的，但是我们难道就一点不做，同时还要发牢骚吗，这里本没有逻辑，这个明明是两个人共同承担，女生为了生活牺牲了工作，而去进行劳务，我们不应该去理解下，为什么要过于批评呢，我们工作时有不好的时候，更何况打扫家务呢，应该互相理解，同时我们是有钱的打工，而她们是免费劳作，她们明明可以有时间去做别的是吧，总之这里我想说的是做人互相理解，双方都不容易，学着互相帮助，互相扶持，生活不就是双方付出与理解的，而不是在理所当然中生存，没有谁的功劳大，所有都是我们自愿的，不要抱怨泼冷水，而是互相包容。
  然后要说的就是李红女儿对其丈夫说的我被困住了，其实这很现实，世界一直在变化，我们如果不前进就会被困住，别人都在接受新东西而我却站在原地与外界隔绝，计算机世界就是这样的世界，不断更新迭代，如果主动逃避就一定会淘汰，如果你想进入就必须有自我学习能力，必须有主动学习，而不是去逃避，我其实发现我之前一直在逃避，将自我封闭，从而缺少了信息获取的能力，缺少自主学习能力，所以我一直在提升这方面的能力，开始拥抱社会与人，就是怕我自己见识短浅，怕我被困住，被淘汰，所以我很有感触，人是需要不断让大脑接受新的知识与刺激的，这样大脑才会有活力，人是需要进行社会活动以及思维活动的人，情商与智商两者都是非常重要的，拥抱世界，让自己的思维打开。
  最后就是李红临走时说的一句话，大致就是我太懦弱了，一直都在等，等这一次还有下一次，人生那有这么多的等待时间与机会，其实我就是等，等我学好了，等我学完了，等我有能力了，我才去做，但是熟不知机会不等人，时间不等人，先进去再说，进去就有机会，而不进去就可能一直都没机会了，你的时间不会等你，青春不等你，更何况这是个借口，是你放松自己，是你逃避压力的借口，不是吗？你说等，但是最后因为压力小了，你就放弃了之前的说的等的目标，选择最后的小目标，说等的就是懦弱的表现，一个借口，是决心觉悟不高的表现，是害怕、胆怯的表现，不是吗？
  最后我想说的是李红做出了选择，这个选择是否正确，如同她独断选择结婚一样，选择是好是坏，没有人在当下做出正确判断，所有这个都是需要我们自己用一生去证明，循规守矩，不走常路，这都是没有绝对的对错，我们可能需要为此付出代价，我们一旦做出了选择，就已经表明我们要用我们自己的时间去检验其正确性了，我想说我要做出用一生去验证的觉悟，可能最后啥也没有，就算这样我也要有豁达胸怀，人生就是这样用一生去做一件事情，最后面对人生经历，一笑置之，离世后多年没有人会记得你到底经历了什么。
